---
name: 寫註解本身會弄壞檔案
description: JSX children 裡的裸 /* */ 編得過而原樣印在畫面上;同名錨在 CSS 與 JS 各一個
type: pitfall
---

為程式碼加註解這個動作本身弄壞檔案七次以上:

- JSX **children 裡的裸 `/* */` 編得過而原樣印在畫面上**(tsc 與 lint 都不紅,只有截圖看得到)
- 表達式位置(三元中間)不能用 `{/* */}`
- 註解內文寫了 `*/` 提前關閉
- 🔴 **用註解文字當 replace 錨,而同一段文字在 CSS 註解與 JS 註解各出現一次** ——
  180 行 JS 被插進 `<style>`,瀏覽器當無效 CSS 靜默吞掉:零錯誤、零反應,
  「點了沒事」與「沒寫」長得一模一樣

**修法**:錨要驗唯一(`assert s.count(anchor) == 1`);改完 HTML 內嵌 JS 用
`node --check` 抽出來驗;前端改動開真瀏覽器看一眼。
