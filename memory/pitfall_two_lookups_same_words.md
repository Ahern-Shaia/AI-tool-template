---
name: 兩種查法都用同一個人的詞,不算兩種
description: 拿競品的詞查自己的 repo,十二格錯十格
type: pitfall
---

對照競品功能時跑了「兩種查法」—— 它的英文 class 名與它的中文 UI 名 —— 都回 0,標「查無」。
**十二格錯十格**:那個功能在我方叫別的名字,兩邊沒有任何共同的字。

**規則**:翻譯不會讓別人的詞變成你的概念。第三種查法 = 先弄清楚那個功能**是什麼**,
再用**自己的概念**找。判準:下「我們沒有」之前,先講得出「那我們是怎麼做這件事的」——
講不出來代表還沒懂,不是沒有。而最難的一種是**它在程式碼裡沒有名字**
(一個 `<input multiple>` 屬性)⇒ 從實作側反查(schema / DOM / 渲染面),不是從想像的功能名。
