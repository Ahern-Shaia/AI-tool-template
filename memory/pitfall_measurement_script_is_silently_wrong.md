---
name: 量測腳本自己會錯,而且是安靜的
description: 探針/量測回的都是「看起來很正常的數字」;自檢要陽性+陰性對照組
type: pitfall
---

單日探針錯十次的輪次不只一次,而**十次都不會 crash** —— 回的都是看起來很正常的數字。

常見形狀:
- `glob(...)[0]` 是**沉默的取樣**(命中兩個檔選錯那個,回 `✓ 0`)
- 工具輸出**被截斷處看起來像清單的結尾**(`head -6`、max-diagnostics、strict-mode 只印前幾筆)⇒ 看 summary 總數,不要數自己 grep 到的行數
- 選擇器猜名字:「找不到」看起來像「產品沒有」
- bbox 在動畫/佈局位移中量到過期值(判別:靠近 → 等落定 → **重量** → 進入)
- 量到的是自己先前操作留下的狀態(sessionStorage 記著上一輪)

**修法**:自檢要**陽性 + 陰性對照組** —— 只有陰性擋不住「探針整個沒跑」;
陽性挑剛出貨的東西。**一面倒的結果特別可疑**(全 0 / 全命中 / 多個對象量出同一個數 = 尺壞了)。
重要結論不能只用一種查法 —— 結論會反轉的那種,查三種。
