全套 e2e 一次 45 紅 —— 隔離逐支重跑後剩 **4 條真紅**,其餘是機器負載下的逾時。

**規則**:一整批紅先隔離重現(單支/小組背對背);`timedOut` 與 `failed`
分開數(混在一起會把真缺陷歸因成「機器忙」);先看 `uptime`,
而 load 有一部分可能是你自己起的 server 忘了停。
事先寫的歸因幾乎一定錯 —— 分「產品壞 / 測試過期 / 環境漂移」逐條驗。
