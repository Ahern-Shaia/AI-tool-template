---
name: 出貨了但沒有人呼叫它
description: 表/服務/端點/測試都在,就是沒有人呼叫;型別與測試都不會紅
type: pitfall
---

一個專案六個「已出貨」模組裡三個底下是空的:guard 從沒讀過 key、
provider 層從沒被呼叫、欄位沒有 reader。共同形狀:
**表 / 服務 / 端點 / 測試都在,就是沒有人呼叫它** —— `tsc` 與測試都不會紅。

變形:
- N 個渲染面接了 N−1 個,漏掉那面印出 fallback(一串字看起來像正常欄位)
- 可覆寫的設定存得進去,而讀取端走 schema default ⇒ 設了等於沒設
- 同一份清單兩個 reader,補了一個忘了另一個

**修法**:出貨前固定 **grep 呼叫端**;修好後 grep **誰還記著舊狀態**
(「已修好」沒回寫到讀者會看的地方,是同一個病的另一半)。
