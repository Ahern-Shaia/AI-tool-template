---
name: 「載入中」與「空的」在程式碼裡長得一樣
description: 空狀態的句子越具體越危險;錯誤/載入/空/有料是四態不是兩態
type: pitfall
---

`data ?? []` 讓「還在載入」與「真的沒有」走同一個渲染分支 ⇒
載入的半秒內畫面說「還沒有任何記錄」—— 句子越具體(「按＋新增第一筆」)越危險。
同族:「錯誤」與「載入中」長得一樣(`useX` 只取 data 與 isPending)⇒
404 的表單長得像一張空表單。

**規則**:loading / empty / error / data 四態分開渲染;
空狀態句子只在**確定為空**時出現;fetch 錯誤要有自己的畫面(含下一步)。
